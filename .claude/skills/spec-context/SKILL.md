# 명세 컨텍스트 수집

대상: $ARGUMENTS

1. `docs/plan/requirements-registry.md`에서 대상 F ID / Epic의 단계, 상태, "주요 설계" 절을 찾는다.
   주제어로 들어오면 `grep -rn "<주제어>" docs/specs/*.md`로 관련 절을 찾는다.
2. 해당 절만 읽는다. 절 경계는 `grep -n "^## " docs/specs/Dxx-*.md`로 확인한다. 문서 전체를 읽지 않는다.
3. D01 §05~06에서 인수 기준을, D06 §04~05에서 관련 테스트·인수 시나리오(T01~T10)를 확인한다.
4. 아래 형식으로 요약한다. 각 항목에 출처 절(`D02 §06`)을 단다.

```
## <대상> 명세 요약
- 단계/상태/Epic:
- 인수 기준:
- 데이터·API 계약: (필드, 한도, 오류 코드, 상태 머신)
- 보안·PII·tenant 제약:
- 기본값·한도 (목표/가정 구분):
- 필수 테스트·장애 주입:
- 선행 작업:
- 명세 간 불일치 또는 미정 사항:
```

5. 불일치·미정 사항이 있으면 임의로 정하지 말고 사용자에게 묻거나 `/adr`을 제안한다.
